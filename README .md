# 《问道长生》游戏介绍

> 九州之大，众生如蚁。有人求长生，有人求快意，有人只求护住一人。
> 灵气潮汐将至，秘境洞开，域外天魔窥伺——你的道，从一粒微尘开始。

《问道长生》是一款**单机修仙文字游戏**。你以一介凡躯踏入仙途，在岁月流转中修行、历劫、结缘、争渡，直至超脱——或者老死山中。每一次行动流逝一月，进度自动存于本机；身死入轮回，还可携宿慧转世再来。

---

## 一、核心玩法：以月为子的修仙人生

游戏的一切都围绕**"每行动一次，流走一月光阴"**展开。打坐、闭关、历练、赴会、鏖战，皆是一月；你要在有限的寿元里，决定每个月花在哪里。

### 二十境 · 四阶

修行共**二十境**，分四大阶，每阶五境：

- **凡俗**：淬体 → 炼气 → 通脉 → 命泉 → 筑台（寿数不变至三百载）
- **真修**：紫府 → 金丹 → 元婴 → 化神 → 还虚（五百至五千载）
- **大能**：窥法 → 洞天 → 天人 → 渡劫 → 半仙（八千至十万载）
- **仙圣**：地仙 → 天仙 → 金仙 → 大罗 → 混元（超脱岁月，与道合真）

设计上，**每个境界的"裸修"耗时约为当前寿元的三分之一**——淬体需三十三载苦功，渡劫需一万六千年。但修仙从来不是苦熬：灵根、资质、功法、洞府、丹药、宗门、师尊、闭关、真文……十余重加成层层相叠，可把万年道途压缩成数载光阴。**修炼的速度，就是你修为的体现。**

### 突破：仙途的三岔口

每个境界分初期、中期、后期、圆满四小阶，小突破看**道心**；大突破则有三条路——

- **人道**：购破境丹，稳妥求成
- **地道**：献天材地宝，附赠根骨
- **天道**：宝物灵珠齐备，直面紫霄雷劫——最险，收益也最高

**渡劫境**起，天道是唯一之路。雷劫落时，可硬抗淬体、可身法闪避、可以攻对劫、可祭法器挡雷，也可提前**渡劫筹备**——护山大阵减雷、道侣护法回血、师尊镇场。雷劫之前，识海或先裂开缝隙：**前世道影化作心魔**，斩之、认之、和之，各有代价。渡劫失败则面临抉择：修为倒退、留下道伤，或**堕入魔道**。

功德挡雷，业力招狠的——因果簿上每一笔都算数。

### 岁月与人情

十二**月令**各有时节（元辰宜修、花朝宜采、鬼月战利尤丰）；数十年一遇的**灵气潮汐**让修炼事半功倍、也让天魔横行；百年轮转的**盛会**——论道大会、坊市大拍、妖王贺寿、仙门大比——是扬名与夺宝的舞台。你可以拜入宗门从外门爬到宗主，收徒传道，开洞府、置灵田、养灵兽，与九位性情迥异的奇人结缘，甚至喜结道侣、开枝散叶。身死或功成皆入轮回，史册记载你的每一世。

## 二、战斗系统：一合定生死的修仙斗法

战斗为**回合制指令战斗**，可六择：**攻击、蓄势绝技、防御、遁走、言语周旋、认输献宝**，丹药符箓随时可用。

### 基础法则

- **战力即一切**：你的战力由境界、阶段、装备、阵纹、炼体、真文等十余重乘区共同决定；每突破一个大境界，战力基础值暴涨 **2.5 倍**，自淬体至混元跨越八个数量级。
- **五行生克**：金木水火土相克，雷风冰三变异灵根各有专长。克制方伤害提升，被克方折损——选对手、选灵根，都是学问。
- **守御减伤**：守御值提供百分比减伤（上限75%），但**永远有保底伤害**——没有无伤的战斗。
- **境界压制**：敌人高你一个大境界，你的伤害只剩四成；高两境，近乎蚍蜉撼树。**打不过就遁走**，遁速决定成败，不丢人。

### 三层技能体系

**其一 · 功法技能**：黄、玄、地、天四阶功法各携成套技能——基础剑诀、御剑诀、万剑归宗、天雷引……技能越用越熟，练至圆满更有几率**觉醒**，威力再涨三成。特定的技能先后手还能触发**连招**（御剑诀接万剑归宗，伤害+50%）。

**其二 · 亲传神通**：与九位奇人情谊至厚（好感80），他们会将**本命神通**倾囊相授——顾清玄的「青莲剑歌」、白凝霜的「霜华天舞」、紫烟的「阴魂蚀骨」、青衣的「诛仙剑引」……直接进入你的战斗技能栏。神通更随情谊**共鸣（好感90）、超限（好感90且结为道侣）**两次觉醒，每重解锁全新效果：连击更多、吸血更深、冻敌更稳。

**其三 · 组合之妙**：
- **连招**：技能之间有先手后手的化学反应；
- **连锁**：不同人的神通先后施展可引爆组合技——青莲剑歌接诛仙剑引，是为「两仪剑阵」，伤害×1.6；
- **专属启灵**：佩其专属法器，神通与器相引（流云飞剑+青莲剑歌＝冷却缩减，诛仙残剑+诛仙剑引＝必暴）。

修到深处，一回合之内：器灵腾空、灵兽扑击、徒弟代师出手、绝技暴击、连锁引爆——层层叠加，一波带走。

### 敌人也会修行

对手不是木桩。凶徒**身怀异术**（断岳斩、血魔噬心咒，按冷却施放）；**濒死之际血脉觉醒**——气血尽数归盈、凶焰大涨，斩杀线本身成为博弈；塔主、秘境之主、深渊领主各有杀手锏。战前情报会告诉你对方境界、异术与变数，**打不打、怎么打、要不要跑，都是决策**。

### 数值哲学

同阶搏杀是真正的五五开偏上（约十余合分胜负），越境是死局，碾压是爽感——战斗的胜负天平，握在你突破前每一个月的选择里。

## 三、养成与追求（简览）

- **法器**：黄玄地天四阶，耐久会损、启灵出词条（暴击/吸血/聚灵），久战孕**器灵**，可成长、可结契、可随你转世
- **真文**：灵魄骨罡遁神六部，自带**杀伐/护道/益生三阵**——同阵凑 2/4/6 件分档解锁套装效果，仙品强化；多余真文**拆纹入道基**，淬炼五行压制之力
- **六文共鸣**：六部齐全，真文护体
- **炼体八重**：从铜皮到不灭金身，气血与攻击双修
- **悟道树**：剑道、丹道、体道、遁法、有情道、器道六系加点
- **道藏集藏**：图鉴收录即得常驻加持——妖兽册强战力、丹药册增丹效、人杰册旺人缘
- **羁绊簿**：道契、命契、亲传神通、专属启灵、连锁反应，一册总览
- **高难**：试炼塔九十九层横跨二十境；**镇魔渊**无尽高难——随机词缀、深渊领主、血脉觉醒，满配玩家的终极试金石；天妖讨伐永不缺席
