## 🎮 游戏简介

《问道长生》是一款单机网页版修仙文字模拟游戏。无需联网，打开即玩，进度自动保存在浏览器本地。你将扮演一名踏上修行路的凡人，在灵气复苏的前夜，于九州大陆经历修炼、突破、炼丹、炼器、宗门争斗、情缘羁绊、秘境探险、渡劫飞升，最终走向属于你的大道结局。

## ✨ 核心特色

### 🌌 十境修真 · 寿元随缘
- **十大境界**：炼气 → 筑基 → 结晶 → 金丹 → 具灵 → 元婴 → 化神 → 悟道 → 羽化 → 登仙
- **小境界**：初期/中期/后期/圆满，每突破增寿元、增气血灵力上限
- **大突破三条路**：
  - **人道**（稳）：吞服破境丹，成功率最高
  - **地道**（宝）：献祭天材地宝，成功率中等
  - **天道**（险）：五行灵珠+渡紫霄雷劫，最险但奖励最丰
- **心魔幻境**：天道雷劫前识海裂开，斩魔/认魔/和魔三选一，各有代价

### ⚔️ 战斗与历练
- 境界压制机制：高你一境近乎碾压，打不过就跑（看遁速）
- 秘境系统：3-5层递深，逐层抉择搜刮/直进/撤退，最深处有秘境之主与孤品
- 灵兽系统：历练遇幼兽，洞府喂养成长，战斗协战、升阶增气血
- 器灵系统：法器久历战阵生灵，四阶成长（初萌→开慧→通灵→化形），可结契同修或纵其天涯

### 🏛️ 宗门体系 · 四级师承
- **22大宗门**分布五洲，分**一/二/三等**：
  - 一等：门槛极高，福利最厚，真传授地阶/天阶传承
  - 二等：门槛适中，内门授玄阶功法
  - 三等：门槛最低，适合散修起步
- **三层身份**：外门 → 内门（贡献晋升） → 真传（贡献再晋升）
- **四级师尊**：长老/峰主/太上长老/宗门门主
  - 需贡献+资质+好感三重门槛
  - 良师：月赠灵石、修炼加成、传授心法、护道突破
  - 差师：放养不教
- **请教系统**：内门弟子可向师尊请教修炼/炼丹/炼器/法术

### 💑 情缘羁绊 · 异性双修
- 9位可攻略NPC（含3位妖族/鬼族），各有4段专属剧情链
- **四阶好感**：陌生(0) → 相识(20) → 知己(40) → 心意暗通(60) → 生死相许(80)
- **机制**：
  - 未结识显示"？？？"，需前往对应区域触发相遇
  - 好感增长减慢10倍，需长期经营
  - 仅异性可双修、结道侣
  - 道侣大限可渡寿元、或散尽修为护一人长生

### 🧪 炼丹 · 16种丹方分级解锁
| 等级 | 丹药示例 | 获取途径 |
|------|----------|----------|
| 基础 | 聚气丹、回春丹、凝神丹、辟谷丹、驱毒丹 | 初始已知、坊市、历练 |
| 进阶 | 破障丹、筑基丹、定魂丹、灵感丹 | 秘境、拜师、宗门兑换 |
| 高阶 | 九转还魂丹、金丹妙药、元婴丹、化神丹、洗髓丹 | 上古遗迹、大能传承、天机拍卖 |

### ⚒️ 炼器 · 17件法器+10级炼器术
- **双轨制**：需**炼器术等级** + **对应图纸** 双重达标
- 炼器术：钻研提升（50石/月，上限10级）
- 图纸：坊市购买、秘境拾获、击败强敌、宗门宝库
- 器有耐久，战损回炉修复，久战可孕育器灵

### 🌍 九州舆图 · 月令潮汐
- **五大洲**：东洲青岳、南疆赤炎、西漠流沙、北原寒渊、中州天阙
- **十二月令**：元辰宜修、花朝宜采、上巳宜会友、鬼月战利丰、中秋双修利……
- **灵气潮汐**：开局数十年后爆发，修炼+25%、秘境丰、天魔入侵，12年后平息

### 🔁 轮回传承 · 跨世图鉴
- **轮回继承**：仙缘+轮回数，承继前世一项觉醒或功法残卷
- **通灵兽衔魂**：亲密度满幼兽随魂转生
- **结契器灵**：魂附残器转世重逢
- **六册图鉴**：丹药、法器、妖兽、秘境、人杰、结局 —— 跨轮回永久收集

## 🎯 快速上手

### 基础操作
- **主界面按钮**：修炼、闭关、历练、静养、突破、地图、坊市、背包、宗门、洞府、炼丹、炼器、情缘、悟道、图鉴、存档
- **自由输入框**：输入任意指令（如"去南疆""拜师""闭关12月""送礼顾清玄""探宝秘境"），游戏会演绎后果
- **存档**：自动保存 + 10个手动档位 + JSON导出跨设备迁移

### 新手建议
1. **创角**：资质+悟性≥15易入名门；天灵根修炼最快；出身选"书香门第"悟性高、或"妖族后裔"走妖修线
2. **早期**：优先拜入二等宗门（如青云宗），外门做任务攒贡献晋升内门
3. **炼丹/炼器**：先钻研基础配方/图纸，灵草矿料留着别全卖
4. **情缘**：先"结识"再"叙话/赠礼/论道"，好感达标触发专属剧情
5. **突破**：道心不足先静养/论道，小突破看道心，大突破备好丹/宝/珠
6. **历练**：境界不足别进高危区域，打不过就跑，保命第一

## 💾 存档与数据

- **自动存档**：每次行动后自动存入 `localStorage` 键 `wdcs_save`
- **手动档位**：存档页 10 个槽位，可覆盖/读取/删除
- **备份机制**：读取其他档位前自动备份当前进度到 `wdcs_backup`
- **跨设备**："导出存档 JSON" 打包进度+图鉴+史册为文件，新设备"导入"即续
- **轮回史册**：每一世结局自动记录，可在卷首/史册页翻阅前尘
