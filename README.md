问道长生
修仙文字游戏 · 网页单文件版

一命一世一蒲团，问道长生路漫漫。

简介
《问道长生》是一款单文件网页修仙文字游戏。你从一介凡人起步，在九州大地上修行、历练、结缘、夺宝，渡过灵气潮汐与天魔之乱，最终走向十一种结局之一——飞升、堕魔、尸解，或只是平淡过完一生。

无需安装、无需联网、无任何依赖：一个 HTML 文件，双击即玩。

快速开始
双击打开 问道长生.html（任意现代浏览器均可）
创建角色：选出身、定道途、掷灵根、配属性
每次行动流逝一月，寿元有限，且行且珍惜
进度自动存于浏览器本机（localStorage），关掉页面不丢；换浏览器或清缓存会丢档。

核心循环
环节	说明
岁月	每行动一次流逝一月，十境修行，修为满则谋突破
突破	小突破看道心；大突破分人道（稳）/ 地道（宝物）/ 天道（渡紫霄雷劫）
战斗	境界压制明显——打不过就跑，不算丢人
历练	采药、遇敌、触发剧情、发现秘境，主要机缘来源
终点	坐化、身死或飞升皆入轮回，转世承宿慧重来
玩法系统
修行
十境体系：炼气 → … → 登仙，逐境突破
悟道树：悟道点点亮丹道、器道、阵道等分支，论道、闭关、破境可得
心魔：雷劫悬顶时识海生魔，前世旧事皆可为魔形——斩之、认之、和之，各有代价
炼丹 & 炼器
炼丹：灵草入炉，「丹道」与「丹药精通」稳炉；九转还魂丹唯自炼可得
炼器：矿料入炉，法剑增战力、护镜增守御；器有耐久，破损即失效，回炉可修
器灵：法器久历战阵孕出器灵（灵蕴满 30 即生）；成长分初萌 → 开慧 → 通灵 → 化形四阶，器效加成 +15% → +80%；可结契同修，魂随轮回
探索
秘境：3~5 层结构，逐层抉择搜刮 / 直进 / 撤退；越深矿越好，守层之主拦路，最深处有秘境之主与孤品
灵气潮汐：开局数十年后降临，修炼 +25%、秘境更丰，域外天魔循隙而至——十二年间页面色调转暗、边框染煞，潮头渐平则回暖
百年盛会：论道大会、坊市大拍、妖王贺寿、仙门大比轮转，状态卡有倒计时
江湖
情缘：六位 NPC 各有四段专属剧情（好感 20/40/60/80 触发），可结道侣
灵兽：历练遇幼兽可收留，协战、升阶，通灵后亲密度满可衔魂随轮回
宿敌：快意恩仇道途独有，一名同步成长的对手每隔数年寻你论剑
出身线：官宦子弟有国师线，妖族后裔有妖修线，亦可在自由输入框主动求之
记录与收集
图鉴：丹药、法器、妖兽、秘境、人杰、结局六册，跨轮回收集，转世不灭
轮回史册：自动记载每一世的姓名、境界、结局
大事记：此生破境、结契、夺魁诸事自动记档——大限时走马灯一盏，照你来时路
月令节气：十二个月各有时节——元辰宜修、花朝宜采、鬼月战利尤丰
十一种结局
结局	达成条件（概要）
问道飞升	渡劫登仙
携侣同升	飞升时有道侣且好感 ≥80
地仙留世	登仙破境且功德 ≥12，触发「大道何往」抉择
尸解	渡劫身死但功德 ≥12
魔堕	业力 ≥15 时渡劫身死；大突破失败亦有半数风险（功德 ≥10 可压制）
护住一人	守护所爱线 HE 分支，道侣渡 25 年寿元相替
问鼎天下	坐化时声望 ≥100（或国师 +60）
人间烟火	一世未破大境界，炼气坐化
继任妖王	化神以上且走完妖修线
坐化轮回	寿尽蒲团，含笑阖眼
身死道消	天地寂静，名字被风带走
灵兽通灵（亲密度满 99）或器灵结契化形，坐化 / 飞升时自动附加随魂效果，下世开局相伴。

操作说明
导航栏：主页 / 地图 / 坊市 / 背包 / 宗门 / 洞府 / 炼丹 / 炼器 / 情缘 / 悟道 / 图鉴 / 帮助
状态卡：默认显示核心三行（境界寿元 / 气血灵力修为 / 月令提示），点「详情 ▾」展开完整属性
自由行动：底部输入框写什么都会被演绎——夜探藏经阁、闭关十年、给心上人送礼……各有后果
存档：右上「存档」手动保存，「放弃今生重开」直接转世
技术说明
单文件 HTML：全部逻辑、样式、数据内嵌，约 160KB
纯原生 JavaScript，无框架、无构建、无网络请求
存档键位：wdcs_save（当前进度）、wdcs_dex（图鉴）、wdcs_chronicle（史册）、wdcs_legacy（轮回次数）、wdcs_lastlife（宿慧继承）
老存档向后兼容：新增字段均有默认值，旧档直接继续玩
